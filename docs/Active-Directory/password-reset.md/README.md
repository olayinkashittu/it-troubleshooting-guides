# Active Directory Password Reset

## Issue

A user has forgotten their password or cannot sign in to their domain account.

## Troubleshooting and Resolution Steps

### 1. Verify the user's identity

Confirm the user's identity according to the organization's IT security procedure before resetting the password.

### 2. Open Active Directory Users and Computers

On the domain controller:

```text
Server Manager
→ Tools
→ Active Directory Users and Computers
