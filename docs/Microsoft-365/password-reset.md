# Microsoft 365 Password Reset Troubleshooting

## Issue

A user cannot sign in to their Microsoft 365 account because they have forgotten their password or are unable to authenticate.

## Common Symptoms

- Incorrect password message
- Repeated sign-in prompts
- User cannot access Outlook
- User cannot access Microsoft Teams
- User cannot access Microsoft 365 services

## Troubleshooting Steps

### 1. Verify the user's identity

Confirm the user's identity using the organization's approved identity-verification procedure.

### 2. Check the account status

Verify that the Microsoft 365 account is active and has not been disabled or blocked.

### 3. Use the approved password reset method

Use the organization's authorized Microsoft 365 administration or self-service password reset process.

Do not ask the user to provide their existing password.

### 4. Create a temporary password when required

If an administrator performs the reset, create a temporary password that meets the organization's password policy.

### 5. Require the user to change the password

Where supported and required by policy, require the user to create a new password at the next sign-in.

### 6. Test authentication

Ask the user to sign in using the approved process.

Test access to:

- Outlook
- Microsoft Teams
- Microsoft 365 web applications

### 7. Check mobile devices and applications

If the user continues receiving authentication errors, check whether other devices or applications are still using old credentials.

## Verification

Confirm that:

- The user can sign in successfully.
- Outlook is working.
- Microsoft Teams is working.
- Required Microsoft 365 services are accessible.

## Resolution

The user's Microsoft 365 password was reset using the approved administrative process and successful authentication was verified.

## Security Best Practice

Never request, record, or store a user's password or authentication codes in troubleshooting documentation.
