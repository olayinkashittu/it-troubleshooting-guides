# IPConfig Commands for IT Support

## Display network configuration

```cmd
ipconfig
```

## Display detailed information

```cmd
ipconfig /all
```

## Release the IP address

```cmd
ipconfig /release
```

## Renew the IP address

```cmd
ipconfig /renew
```

## Flush the DNS cache

```cmd
ipconfig /flushdns
```
