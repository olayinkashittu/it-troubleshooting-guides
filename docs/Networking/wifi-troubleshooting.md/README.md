# Wi-Fi Troubleshooting

## Issue

The computer cannot connect to a wireless network.

## Troubleshooting Steps

### 1. Restart the router.

### 2. Forget the Wi-Fi network.

### 3. Reconnect to the network.

### 4. Run the Windows network troubleshooter.

### 5. Update the wireless adapter driver.

## Commands

```cmd
netsh wlan show profiles
```

```cmd
ipconfig
```

## Resolution

Wireless connectivity restored.
