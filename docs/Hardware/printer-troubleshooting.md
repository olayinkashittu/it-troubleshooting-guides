# Printer Troubleshooting

## Issue

A printer is not printing, is offline, produces poor-quality output, or cannot be reached by the user.

## Common Symptoms

- Printer is offline
- Print jobs remain in the queue
- Printer does not respond
- Poor print quality
- Paper jams
- Printer cannot be found
- Network printer connection fails
- Driver errors

## Troubleshooting Steps

### 1. Check Power

Confirm that:

```bash
- The printer is powered on.
- The power cable is connected securely.
- The printer displays no hardware error.
```

### 2. Check the Connection

For a USB printer:

```bash
- Check the USB cable.
- Try another USB port when appropriate.
```

For a network printer:

```bash
- Confirm the printer is connected to the network.
- Check the printer's IP address.
- Verify the computer can reach the printer.
```

### 3. Check Printer Status

Open:

Settings

```bash
→ Bluetooth & devices
→ Printers & scanners
```

Select the affected printer and review its status.

Confirm that the correct printer is selected.

### 4. Clear the Print Queue

Open the printer's print queue and remove jobs that are stuck.

Then send a new test document.

### 5. Restart the Print Spooler

Open:

```bash
→ Bluetooth & devices
→ Printers & scanners
```
